JsEngine

A TypeScript game engine built on an archetype ECS modelled on Unity DOTS, rendering entirely to a terminal with ANSI escape codes. Here the terminal is xterm.js and the world runs in a Web Worker, the same code that runs in a real terminal under node or bun.

2D

Sprites composited into half-block cells, with thousands of entities fading colour through ECS systems.

3D

A software rasterizer: OBJ meshes from binary mesh caches, textures, Blinn-Phong lighting and level of detail, threaded where the page is cross-origin isolated. The bugatti downloads on demand.
