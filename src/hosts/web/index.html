JsEngine

A TypeScript game engine built on an archetype ECS modelled on Unity DOTS, rendering to a grid of terminal cells. Here the world runs in a Web Worker and its cells are drawn onto a canvas, the same code that writes ANSI escape codes to a real terminal under node or bun.

Swarm

A twin-stick survival game built on the engine: waves of enemies close in from every edge, an ECS grid broadphase resolves the hits, and clearing waves earns bombs.
